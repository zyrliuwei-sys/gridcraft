# Resource sections specification

Build src/blocks/gridcraft-resources.tsx and src/styles/gridcraft-resources.css only. Export GridcraftResources. Include your bilingual translation keys in docs/research/resources-messages.json as {en:{...},zh:{...}}, do not edit shared messages files. Use m['gc.resources.*'] for all visible copy; envConfigs.app_name for site brand. Link from @/core/i18n/navigation.

Design: Flora-inspired black canvas technical learning site. Global tokens: --gc-bg, --gc-panel, --gc-text, --gc-muted, --gc-line, --gc-mint and --gc-serif (Instrument Serif), body DM Sans. Content container max-width 1240px, padding 36px desktop/20px mobile. Sections padding 92px 0. H2 serif weight 400, 48px desktop/36px mobile. Small text 14px gray. Panel corners 12px, 1px border. Mint only for actions/highlights; onyx, muted blue and pale mint illustrations/screenshots. No large gradient backgrounds. Cards should use actual upstream images at /imgs/gridcraft/{budget,grades-formulas,pivot,format-chart,hero}.webp (root downloading). No generated images needed. Hero handled by parent, don't duplicate hero. Actual copy based on official upstream source, not invented performance percentages.

Sections:

1. #features: two-column text + real upstream screenshot, heading 'Familiar cells. Fresh possibilities.' Brief feature points on XLSX native format, 500+ functions, local Rust/WASM, alpha note. Buttons link /editor and #learn. Small feature facts in horizontal row, not a uniform three-card layout.
2. #learn: title 'A little guidance. A lot of possibility.' Resource cards in asymmetric 2:1:1 or two-column layout with real screenshot thumbnails. Filter buttons All guides, Getting started, Formulas, Analysis; functional click filters. Each opens an accessible shadcn Dialog or native dialog with actionable English tutorial text (opening XLSX, SUM/IF examples, building chart/PivotTable) and editor link /editor. Include actual steps, not dead links. Guide data in block uses message functions, reusable component props. Don't create route pages unless necessary.
3. #compare: 'Your spreadsheet. Your choice.' Semantic comparison table (~6 rows) GridCraft vs Microsoft Excel: open source MIT/Apache vs proprietary, free vs free web/paid desktop options, Windows/macOS/Linux/web vs Windows/macOS/web, local XLSX workflow vs OneDrive collaboration, VBA macros not supported vs desktop VBA, alpha vs mature ecosystem. Link official project and Microsoft sources. No price numbers or unsupported speed rankings.
4. #download: 'Make room for better work.' Functional tabs macOS/Windows/Linux, exact current v0.7.0 verified download links https://github.com/storytold/gridcraft/releases/download/v0.7.0/gridcraft-0.7.0-macos-universal.dmg and windows-x64.msi and linux-x86_64.AppImage; include architecture label, concise correct install steps, all releases link for other architectures. Save before close alpha reminder. Do not auto-start downloads on tab selection.
5. #faq: 4-5 native details disclosures with facts: free/open source, independent site affiliation, file compatibility/alpha, browser local and export, VBA limits. Include community help external https://discord.gg/artcraft; don't claim staffed human support or fake AI chat.

Responsive 1440/768/390; table has horizontal scrolling if needed, no page-level overflow. All interactions keyboard accessible, visible focus. Respect reduced motion. No commits, no global edits, no UI primitive edits. Parent handles build.
